# Questions for Knight

Each question names the assumption Lane makes until it is answered ([ASSUMPTIONS.md](ASSUMPTIONS.md)).
Most answers change a setting in the ruleset, not code.

| # | Question | Until answered (assumption) |
|---|---|---|
| Q1 | Does "non-listed states" under prohibited exposures mean where the account is based, or where its trucks operate? If operations, what share of miles outside the program states is acceptable, and is it measured by IFTA miles? | Both readings are evaluated; either declining makes it a potential decline (A03, 5% tolerance) |
| Q2 | Which address decides the account's state: garaging, mailing, or principal place of business? | Garaging, else mailing (A01) |
| Q3 | Should the 60-day loss run and 90-day MVR windows count from the application date or the requested effective date? | Application date, with the effective date checked too (A02) |
| Q4 | For lithium battery cargo, should loads that may contain lithium (appliances, electronics) be declined, referred, or only confirmed? | Flag and confirm (A04) |
| Q5 | Does a loss history letter stating "no paid losses" satisfy "losses reported for every prior term", or is a carrier loss run required? | A loss run is required (A08) |
| Q6 | What makes a license "valid U.S. driver license and CDL"? | The MVR alone: valid status on the state record (A10) |
| Q7 | Is the point threshold measured from the violation date or the conviction date? | Violation date (A11) |
| Q8 | When an owner is listed as a driver but answers that the owner does not drive, should the account be referred, or is a named driver exclusion enough to proceed? | Refer as a potential decline until confirmed (A06) |
| Q9 | For corporations that are new ventures, what does "subject to underwriter review" require? | Refer (rule ELIG-07) |
| Q10 | When documents disagree on the number of power units, which source governs routing? | Every count is considered; straddling the line goes to Fleet (A15) |
